# Abu Dhabi Harlequins — Quins Club Hub

Club-management PWA for Abu Dhabi Harlequins RFC: fixtures, roster and
per-player availability, with role-based access enforced server-side by
Supabase Row-Level Security.

See `claude/archive/quins-v1-mvp.md` for the implementation plan and
`claude/specs/design-system.md` for the visual spec.
