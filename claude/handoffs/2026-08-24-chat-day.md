## Traps that cost time today — for the next session

- **The changelog hand-off is now a rhythm**: every PR cites the PREVIOUS
  squash SHA; local docs:check reds on multi-commit branches are the
  documented false positive both directions. Next PR must cite the #368-era
  docs squash, whatever it becomes.
- **A stacked branch + two parallel sessions means `main` moves mid-PR** —
  #366 went DIRTY three times. Merge main in, union the changelog, keep
  going; AppShell merged cleanly every time.
- **The bottom-right corner is the dock's** (since #367). Anything new that
  floats must stack above it, not share it — the HelpButton collision was
  found in the harness, not in review.
- **Same-transaction `now()` is constant** — harness time-comparisons need
  superuser backdating (see db/tests/group-chats.sql assert 12).
- **`git checkout` carries uncommitted work between branches silently** —
  twice this session work landed on the wrong branch and had to be walked
  back. Check `git branch --show-current` before every commit.
- The deliberate-fail-first harness discipline caught two real migration
  bugs (welfare_overview copied from the wrong source; leave_group deleting
  reported evidence) before they reached production.
